# PROG6121-RaceDay-Part-1-GR4
A full stack race event management system
RACEDAY ACTIVITIES MANAGEMENT SYSTEM

SYSTEM DESCRIPTION

The RaceDay Activities Management System is a database-driven system designed to manage race and sporting event activities. The system stores and manages information about administrators, participants, event types, events, event categories, enrolments, routes, weather information, and race results.

The system uses a relational database called RaceDayActivitiesDB, developed using Microsoft SQL Server and SQL Server Management Studio (SSMS). The database uses primary keys and foreign keys to establish relationships between tables and maintain data integrity.

The system allows race organisers to manage event information, register participants for event categories, record payments and enrolments, manage race routes, capture weather information, and record participant results.

USER ROLES

1. ADMINISTRATOR

The Administrator is responsible for managing and maintaining the RaceDay Activities system. Administrators can manage event information, event types and categories, participant information, enrolments, routes, weather information, and race results.

The Administrator can:
- Manage race and sporting events.
- Manage event types and event categories.
- View and manage participant information.
- Manage participant enrolments.
- Record and manage payment information.
- Manage race routes.
- Record weather forecasts and related information.
- Capture and manage participant race results.
- Maintain accurate and consistent system data.

2. PARTICIPANT

The Participant is a person who registers to take part in a race or sporting event managed by the system.

Participants can:
- Provide their personal and contact information.
- Register for available event categories.
- Provide identification information using an identity number or passport number.
- View their enrolment and registration information.
- Provide or maintain emergency contact information.
- Participate in the selected race or sporting activity.
- Have their payment and race results recorded in the system.

DATABASE STRUCTURE

The RaceDayActivitiesDB database consists of the following tables:

- Admins
- Participants
- EventTypes
- Events
- EventCategories
- Enrolments
- Routes
- Weather
- Results

The tables are connected using primary keys and foreign keys to create relationships between related information and reduce data duplication.

TECHNOLOGIES USED

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
- Relational Database Design

PROJECT PURPOSE

The purpose of the RaceDay Activities Management System is to provide an organised and reliable way of managing sporting events and participant information. It ensures that event, registration, payment, weather, route, and results information can be stored and accessed efficiently while maintaining data integrity through database constraints and relationships.
